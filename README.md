                                                                                                LLM-RAG
Projeto desenvolvido como parte de uma Iniciação Científica com o objetivo de investigar o uso de **Large Language Models (LLMs)** combinados com **Retrieval-Augmented Generation (RAG)** como ferramenta de apoio à aprendizagem.

O sistema utiliza materiais acadêmicos como base de conhecimento e recupera informações relevantes antes de gerar uma resposta, buscando produzir respostas mais contextualizadas e fundamentadas no conteúdo fornecido.
